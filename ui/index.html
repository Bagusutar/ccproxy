代理设置

本地代理自身的监听、启动方式，以及面向不稳定上游的容错阈值。
当前以管理员权限运行。Windows 的 UIPI 特权隔离规定：非提权程序的全局键盘钩子， 在提权窗口获得焦点时收不到按键，因此本窗口位于前台时全局热键会失效。 本程序不需要管理员权限，该状态通常由管理员终端启动时的权限继承造成，关闭后双击重新运行即可。
监听与启动
监听端口
端口被占用时自动顺延
开机自启
在当前用户的注册表 Run 键写入一项，登录 Windows 后自动启动后台代理。不需要管理员权限
容错阈值
重试守护
写入 CLAUDE_CODE_RETRY_WATCHDOG=1，使 Claude Code 对瞬时错误采用更长的重试退避
超时重发
秒
上游超过该时长未返回响应头即自动重发。此时客户端尚未收到任何数据，重发不会产生重复内容
静默上限
秒
上游已开始返回、随后超过该时长没有任何数据（含 SSE 心跳）时，提前结束本次响应并交还控制权
Claude Code 自身需等待 300 秒才放弃，上述两项应明显小于该值才有意义。

接入其他工具

将下方地址与凭证填入任何支持自定义 API 端点的工具。 代理依据请求体中的 model 选择上游，替换凭证后转发。
本地地址
地址
凭证
凭证可填任意值，代理会替换为对应上游的真实凭证；真实密钥不会离开本机。
代理仅监听 127.0.0.1，本机以外无法访问，本机上的任何程序均可使用。

Codex

            
可用

          

          

            按上方「Codex」标签页的内容写入 ~/.codex/config.toml。
            Codex 只使用 /v1/responses，模型需选择上游在该接口上提供的那些；
            Claude 系模型走该接口通常返回 convert_request_failed。
          


          

            
Cursor

            
不可用

          

          

            Cursor 的对话请求由 Cursor 的服务器发出，而非本机，因此无法访问
            127.0.0.1，返回 Access to private networks is forbidden。
            设置页的验证按钮由客户端直接发起，能够连通本代理，所以会出现「验证通过、对话失败」。
            接入需要把本代理暴露到公网，本程序不提供该能力。
          


          

            可接入的条件有两条：工具支持自定义 API 端点，且请求由本机发出。
            把请求交给自家服务器再转发的工具无法接入，本代理只监听 127.0.0.1。
            在本机发起请求的 Anthropic 或 OpenAI 兼容客户端均可直接使用。
          

        


        

          支持的接口
          

            

              
路径说明

              
                
POST /v1/messagesAnthropic Messages，转发到上游的地址

                
POST /v1/messages/count_tokens上游不支持该端点时由本地估算

                
POST /v1/chat/completionsOpenAI Chat Completions，转发到OpenAI 地址

                
POST /v1/responsesOpenAI Responses，同上

                
GET  /v1/models本地合成，返回所有上游模型的并集

              
            

            

              填写地址时带不带 /v1 均可，两种写法都会正确落到上述路径。
              其余路径原样转发，不做改写。上游未实现某条路径时，返回其自身的 404。
